**dashboard-grid.tsx:**
Create a responsive grid component using react-grid-layout:

```typescript
import GridLayout, { Responsive, WidthProvider } from "react-grid-layout";
import "react-grid-layout/css/styles.css";
import "react-grid-layout/css/resizable.css";

const ResponsiveGridLayout = WidthProvider(Responsive);

interface DashboardGridProps {
  widgets: WidgetConfig[];
  layouts: ResponsiveLayouts;
  onLayoutChange: (layout: Layout[], layouts: ResponsiveLayouts) => void;
  isEditing: boolean;
  onWidgetSelect?: (widgetId: string) => void;
  selectedWidgetId?: string | null;
}
```

Configuration:

- breakpoints: { lg: 1200, md: 996, sm: 768, xs: 480 }
- cols: { lg: 12, md: 10, sm: 6, xs: 4 }
- rowHeight: 50
- isDraggable/isResizable: controlled by isEditing prop
- compactType: 'vertical'
- preventCollision: false

Debounce onLayoutChange by 300ms to prevent excessive API calls.
Render WidgetRenderer for each widget inside grid items.
