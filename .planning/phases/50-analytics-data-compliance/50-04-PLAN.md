**Methods to add/enhance:**

- `createSchedule(orgId, userId, dto)`: Create schedule and register BullMQ repeating job
- `updateSchedule(orgId, scheduleId, dto)`: Update schedule, re-register job if timing changed
- `deleteSchedule(orgId, scheduleId)`: Remove schedule and cancel BullMQ job
- `pauseSchedule(orgId, scheduleId)`: Set isActive=false, remove BullMQ job
- `resumeSchedule(orgId, scheduleId)`: Set isActive=true, re-register BullMQ job
- `runNow(orgId, scheduleId)`: Trigger immediate execution via BullMQ

**Cron pattern generation:**

- DAILY: `0 ${hour} * * *` (e.g., "0 8 \* \* \*" for 8 AM daily)
- WEEKLY: `0 ${hour} * * ${dayOfWeek}` (e.g., "0 8 \* \* 1" for Monday 8 AM)
- MONTHLY: `0 ${hour} ${dayOfMonth} * *` (e.g., "0 8 1 \* \*" for 1st of month 8 AM)

**scheduled-report.processor.ts:**
Create BullMQ processor for scheduled report execution:

```typescript
@Processor("scheduled-reports", { concurrency: 3 })
export class ScheduledReportProcessor extends WorkerHost {
  constructor(
    private readonly reportService: ReportExecutionService,
    private readonly mailerService: MailerService,
    private readonly scheduleService: ReportScheduleService,
    private readonly logger: Logger,
  ) {
    super();
  }

  async process(
    job: Job<ScheduledReportJobData>,
  ): Promise<{ success: boolean }> {
    const { scheduleId, organizationId, reportId, recipients, format } =
      job.data;

    // 1. Execute report
    const execution = await this.reportService.execute({
      reportId,
      organizationId,
      format,
      triggeredBy: "SCHEDULED",
      scheduleId,
    });

    // 2. Send email with attachment
    await this.mailerService.sendMail({
      to: recipients,
      subject: `Scheduled Report: ${execution.report.name}`,
      template: "scheduled-report",
      context: {
        reportName: execution.report.name,
        downloadUrl: execution.outputFileUrl,
        generatedAt: new Date().toISOString(),
      },
      attachments: [
        {
          filename: execution.outputFileName,
          path: execution.outputFilePath,
        },
      ],
    });

    // 3. Update schedule status
    await this.scheduleService.updateAfterRun(scheduleId, "SUCCESS", job.id);

    return { success: true };
  }
}
```
