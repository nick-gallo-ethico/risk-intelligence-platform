<objective>
Pin JWT algorithm to RS256 only and validate required secrets on startup.

Purpose: SEC-03 (algorithm confusion attack CVE-2015-9235), SEC-04 (undefined secret vulnerability), and SEC-10 (tenant middleware JWT verification). Currently auth.module.ts and jwt.strategy.ts accept both RS256 and HS256, allowing attackers to forge tokens using the public key as HMAC secret. Additionally, JWT_REFRESH_SECRET may be undefined which creates tokens signed with empty string. Tenant middleware uses hardcoded secret instead of JwtKeyService.

Output: All JWT verification uses RS256 only; undefined secrets cause startup failure; tenant middleware uses proper key service
</objective>
