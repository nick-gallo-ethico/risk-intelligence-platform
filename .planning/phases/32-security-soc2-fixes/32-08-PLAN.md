  <action>
Run comprehensive automated checks for all security fixes.

1. TypeScript compilation:

   ```bash
   cd apps/backend && npx tsc --noEmit
   ```

2. Linting:

   ```bash
   cd apps/backend && npm run lint
   ```

3. SEC-01 verification - no hardcoded tenant IDs:

   ```bash
   echo "=== SEC-01: Checking for hardcoded tenant IDs ==="
   grep -rn "TEMP_ORG_ID\|TEMP_USER_ID\|stub-org-id\|stub-user-id" \
     apps/backend/src/modules/campaigns/ \
     apps/backend/src/modules/disclosures/ \
     apps/backend/src/modules/investigations/checklists/ \
     apps/backend/src/modules/analytics/migration/ \
     apps/backend/src/modules/policies/approval/ \
     2>/dev/null && echo "FAIL: Hardcoded IDs found" || echo "PASS: No hardcoded IDs"
   ```

4. SEC-02 verification - WebSocket JWT verification:

   ```bash
   echo "=== SEC-02: Checking WebSocket auth ==="
   grep -n "verifyAsync" apps/backend/src/modules/ai/ai.gateway.ts && echo "PASS: JWT verification present" || echo "FAIL: Missing JWT verification"
   grep -n "auth.organizationId\|auth.userId" apps/backend/src/modules/ai/ai.gateway.ts && echo "FAIL: Client trust found" || echo "PASS: No client trust"
   ```

5. SEC-03 verification - RS256 only:

   ```bash
   echo "=== SEC-03: Checking algorithm pinning ==="
   grep -rn "HS256" \
     apps/backend/src/modules/auth/auth.module.ts \
     apps/backend/src/modules/auth/strategies/jwt.strategy.ts \
     apps/backend/src/modules/auth/services/token-refresh.service.ts \
     2>/dev/null && echo "FAIL: HS256 still present" || echo "PASS: No HS256 in verification"
   ```

6. SEC-04 verification - startup validation:

   ```bash
   echo "=== SEC-04: Checking startup validation ==="
   grep -n "throw new Error.*JWT_REFRESH_SECRET\|FATAL.*JWT" apps/backend/src/modules/auth/services/token-refresh.service.ts && echo "PASS: Startup validation present" || echo "FAIL: Missing startup validation"
   ```

7. SEC-05 verification - organizationId removed from DTO:

   ```bash
   echo "=== SEC-05: Checking chat DTO ==="
   grep -n "organizationId" apps/backend/src/modules/ai/dto/chat-message.dto.ts && echo "FAIL: organizationId still in DTO" || echo "PASS: organizationId removed"
   ```

8. SEC-06 verification - no hardcoded password:

   ```bash
   echo "=== SEC-06: Checking demo password ==="
   grep -n "Password123" apps/backend/src/modules/demo/demo.service.ts && echo "FAIL: Hardcoded password found" || echo "PASS: No hardcoded password"
   grep -n "randomBytes\|generateSecurePassword" apps/backend/src/modules/demo/demo.service.ts && echo "PASS: Secure generation present" || echo "FAIL: Missing secure generation"
   ```

9. SEC-07 verification - MaxLength on password:

   ```bash
   echo "=== SEC-07: Checking password validation ==="
   grep -n "MaxLength(72)" apps/backend/src/modules/auth/dto/login.dto.ts && echo "PASS: MaxLength present" || echo "FAIL: Missing MaxLength"
   ```

10. SEC-09 verification - MFA in JWT:

    ```bash
    echo "=== SEC-09: Checking MFA in JWT ==="
    grep -n "mfaVerified" apps/backend/src/modules/auth/interfaces/jwt-payload.interface.ts && echo "PASS: mfaVerified in interface" || echo "FAIL: Missing mfaVerified"
    grep -n "mfaVerified.*true" apps/backend/src/modules/auth/mfa/mfa.service.ts && echo "PASS: mfaVerified set after verify" || echo "FAIL: mfaVerified not set"
    ```

11. SEC-11 verification - audit logging:

    ```bash
    echo "=== SEC-11: Checking audit logging ==="
    grep -c "auditService.log" apps/backend/src/modules/messaging/relay.service.ts | { read count; [ "$count" -ge 3 ] && echo "PASS: $count audit log calls" || echo "FAIL: Only $count audit log calls"; }
    ```

12. SEC-12 verification - operations exemption:

    ```bash
    echo "=== SEC-12: Checking operations exemption ==="
    grep -n "operations/\.\*\|operations/(.*)" apps/backend/src/app.module.ts && echo "FAIL: Blanket exemption found" || echo "PASS: No blanket exemption"
    ```

13. SEC-13 verification - PII in logs:

    ```bash
    echo "=== SEC-13: Checking PII in logs ==="
    grep -n "logger.*email\|logger.*user.email" apps/backend/src/modules/auth/mfa/mfa.service.ts && echo "FAIL: Email in logs" || echo "PASS: No email in logs"
    ```

14. Run existing unit tests to check for regressions:
    ```bash
    cd apps/backend && npm run test -- --passWithNoTests 2>&1 | tail -20
    ```

Report any failures for human review.
