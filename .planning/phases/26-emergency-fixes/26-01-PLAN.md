Modify the `withBypassRLS()` method (lines 53-60) to handle `disableBypassRLS()` failures:

1. Add Logger import from `@nestjs/common` (already imported, verify)
2. Add private logger instance: `private readonly logger = new Logger(PrismaService.name);`
3. Wrap the `disableBypassRLS()` call in the finally block with try-catch:

```typescript
async withBypassRLS<T>(callback: () => Promise<T>): Promise<T> {
  await this.enableBypassRLS();
  try {
    return await callback();
  } finally {
    try {
      await this.disableBypassRLS();
    } catch (error) {
      // CRITICAL: If disableBypassRLS fails, the connection has bypass_rls=true
      // stuck. We MUST destroy all pooled connections to prevent data leakage.
      this.logger.error(
        'SECURITY: Failed to disable RLS bypass. Destroying connection pool to prevent data leakage.',
        error instanceof Error ? error.stack : String(error),
      );
      await this.$disconnect();
      throw error; // Re-throw so caller knows the operation had a critical failure
    }
  }
}
```

Key behaviors:

- On disableBypassRLS() failure, log SECURITY alert
- Destroy entire connection pool with `$disconnect()` (Prisma terminates all connections)
- Re-throw error so caller knows operation failed critically
- Do NOT return the callback result if cleanup failed
