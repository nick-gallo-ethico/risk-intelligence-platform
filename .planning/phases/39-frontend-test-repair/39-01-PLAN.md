Create the test utility file with:

   ```typescript
   const createTestQueryClient = () =>
     new QueryClient({
       defaultOptions: {
         queries: { retry: false, gcTime: 0 },
         mutations: { retry: false },
       },
     });
   ```

   - `gcTime: 0` (garbage collection time, formerly cacheTime) ensures no cache pollution between tests

2. **AllTheProviders wrapper component:**
   - Creates fresh QueryClient for each render
   - Wraps children in QueryClientProvider

3. **renderWithProviders function:**
   - Accepts ReactElement and optional RenderOptions (excluding wrapper)
