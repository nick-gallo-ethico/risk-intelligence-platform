  <name>Task 3: Strip restating JSDoc comments</name>
  <files>apps/backend/src/modules/**/*.ts</files>
  <action>
Find and remove JSDoc comments that add no value beyond the method signature.

**Pattern to remove:**

```typescript
// REMOVE - restates the obvious
/**
 * Delete a feature flag.
 */
async deleteFlag(id: string): Promise<void> { ... }

// KEEP - adds context beyond signature
/**
 * Delete a feature flag. Active flags cannot be deleted; disable first.
 * @throws BadRequestException if flag is still active
 */
async deleteFlag(id: string): Promise<void> { ... }
```

**Criteria for removal:**

- JSDoc contains ONLY method name restated as sentence
- No @param descriptions (or just "@param id - the id")
- No @returns description beyond type
- No @throws documentation
- No usage examples or warnings

**Process:**

1. Search for JSDoc patterns: `/** ... */`
2. For each JSDoc:
   - If it only restates method name -> remove entire JSDoc block
   - If it has ANY additional context -> keep it

**Files likely to have restating JSDoc (from git status):**

- dto files (many have `/** Create DTO */` type comments)
- service files with CRUD methods

Use search:

```bash
cd apps/backend && grep -B1 -A3 "^\s*/\*\*" src/modules/feature-flags/ | head -100
```

Be conservative - when in doubt, keep the JSDoc.

SLOP-10: Remove noise without losing documentation value.
</action>
