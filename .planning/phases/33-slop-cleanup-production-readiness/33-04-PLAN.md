<task type="auto">
  <name>Task 1: Remove separators from common/ and config/</name>
  <files>
apps/backend/src/common/**/*.ts
apps/backend/src/config/**/*.ts
  </files>
  <action>
Use VS Code or IDE regex find/replace with preview to remove section separator comments.

**Pattern to match pure separators (no descriptive text):**

```regex
^[ \t]*//[ \t]*[=\-]{3,}[ \t]*\n
```

**Pattern to match separator blocks with headers:**

```regex
^[ \t]*//[ \t]*[=\-]{3,}.*\n([ \t]*//.*\n)*[ \t]*//[ \t]*[=\-]{3,}.*\n
```

**Process:**

1. Open each file in the directory
2. Find lines matching `// ===` or `// ---` with 3+ characters
3. If the line is ONLY separator characters (// =====), delete the entire line
4. If the line has text after separator (// ===== CRUD OPERATIONS =====), keep the text as a simple comment:
   - BEFORE: `// ============ CRUD OPERATIONS ============`
   - AFTER: `// CRUD OPERATIONS`

Files in common/:

- activity.module.ts, controllers/, dataloader/, decorators/, dto/, filters/, guards/, interceptors/, middleware/, services/

Files in config/:

- configuration.ts and any other config files

**Important:** Review each change before applying. Some separators mark logical sections - preserve the section name as a simple comment.

SLOP-04: Remove visual noise while preserving documentation value.
</action>
<verify>
Run: `cd apps/backend && grep -rn "// ===\|// ---" src/common/ src/config/ | wc -l`
Expected: 0 or very low count (descriptive headers converted to simple comments).
</verify>
<done>All pure separator lines removed from common/ and config/, descriptive headers converted to simple comments.</done>
</task>
