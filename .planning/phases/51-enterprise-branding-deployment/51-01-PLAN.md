```prisma
model TenantBranding {

  // Enterprise branding fields (NEW)
  customDomain       String?  @map("custom_domain")        // BRAND-01 (e.g., "ethics.acme.com")
  heroImageUrl       String?  @map("hero_image_url")       // BRAND-03
  showPoweredBy      Boolean  @default(true) @map("show_powered_by")  // BRAND-05
  footerHtml         String?  @map("footer_html")          // BRAND-06 (sanitized HTML)
  customCss          String?  @map("custom_css")           // BRAND-07 (sanitized CSS)
  emailSenderDomain  String?  @map("email_sender_domain")  // BRAND-04
  emailDomainStatus  String?  @map("email_domain_status")  // pending|verified|failed
  customFonts        Json?    @map("custom_fonts")         // BRAND-02 (array of font definitions)
}
```

Fields explained:

- `customDomain`: Custom domain for the tenant's ethics portal (e.g., "ethics.acme.com")
- `heroImageUrl`: URL to hero image in Azure Blob Storage
- `showPoweredBy`: Boolean toggle for "Powered by Ethico" badge
- `footerHtml`: Sanitized HTML for custom footer content
- `customCss`: Sanitized CSS for enterprise customization
- `emailSenderDomain`: Custom domain for email sending (e.g., "notifications.acme.com")
- `emailDomainStatus`: SPF/DKIM verification status
- `customFonts`: JSON array of {fontFamily, fontWeight, fontStyle, url} objects
