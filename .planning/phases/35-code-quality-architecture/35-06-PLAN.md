    **Step 3: Fix strictPropertyInitialization errors**

    strict: true enables strictPropertyInitialization which will flag uninitialized properties.

    For NestJS DI properties, use definite assignment assertion:
    ```typescript
    @Inject(SomeService)
    private readonly someService!: SomeService;  // ! is correct here
    ```

    For class properties that are initialized later:
    ```typescript
    // Option 1: Initialize in declaration
    private items: string[] = [];

    // Option 2: Definite assignment (if initialized in constructor or lifecycle method)
    private client!: ApiClient;  // Initialized in onModuleInit

    // Option 3: Make optional
    private cache?: Map<string, unknown>;
    ```

    **Step 4: Fix useUnknownInCatchVariables errors**

    strict: true enables useUnknownInCatchVariables which makes catch(e) type unknown.

    ```typescript
    // Before
    try { ... }
    catch (error) {
      console.log(error.message);  // Error: unknown has no 'message'
    }

    // After
    try { ... }
    catch (error) {
      if (error instanceof Error) {
        console.log(error.message);
      } else {
        console.log('Unknown error:', error);
      }
    }
    ```

    **Step 5: Fix any remaining strict mode errors**

    Run compiler repeatedly, fixing errors in batches until clean.
